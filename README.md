# Phoenix: Tesla Network
### A GregTech Modern Capstone Addon | 1.20.1

> "The present is theirs; the future, for which I really worked, is mine." — Nikola Tesla

**Phoenix: Tesla Network** is a high-fidelity expansion for GregTech Modern, centered around the concept of **Capstone Multiblocks**. This isn't just another tier of machines; it is a reward for the dedicated engineer—a massive, visually stunning infrastructure project that redefines power and data distribution.

---

## ⚡ The Capstone Philosophy
In this mod, we reject the "spamming singleblocks" meta. **Capstone Multiblocks** are designed to be:

* **Unique:** You don't build rows of these. You build *one* or *two* as the heart of your base.
* **Aesthetic:** Built for full-stop renders. Expect custom shaders, complex particle systems, and massive scale.
* **Earned:** A true Tier reward. If you see a Tesla Tower on the horizon, it means you've conquered the tech tree.

---

## 📡 The Tesla Network
The core of this addon is the **Tesla Tower**, a wireless power and data orchestration hub. 

* **Wireless Distribution:** High-voltage energy transmission through the air, rendered with custom lightning arcs.
* **Integrated Core:** Built upon the stability of **PhoenixCore**, ensuring robust NBT synchronization and server-side performance for massive structures.
* **Singleblock Hater Approved:** True multiblocks only. If it fits in one block, it isn’t powerful enough.
